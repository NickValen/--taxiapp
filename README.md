# 🚕 Жёлтый — демо-сервис такси

Интерактивное такси по мотивам центров пяти европейских городов: **Париж, Амстердам, Вена, Рим, Лондон**.
Карта с улицами, реками и достопримечательностями, водители на дорогах, пробки и перекрытые улицы, динамические цены, история поездок, отзывы и чат поддержки.

> **Про карты.** Они схематичные: названия улиц и достопримечательностей настоящие, но геометрия городов
> сгенерирована программой. Это не данные OpenStreetMap.

## Возможности

- 5 городов с разной планировкой (реки, мосты, парки, главные проспекты)
- ~35 объектов в каждом городе: достопримечательности, школы, музеи, суды, магазины, ТЦ, отели, рестораны, остановки
- Заказ поездки: выбор точек «откуда» и «куда» кликом по карте, быстрый выбор мест, три тарифа
- Маршруты с учётом пробок (🔴 🟠) и перекрытий (🚧), описание пути по улицам
- Водители в реальном времени: подача, посадка, поездка
- Динамическая цена: чем меньше свободных машин, тем выше коэффициент спроса. Кнопка «Час пик» разгоняет спрос
- История поездок, отзывы, поддержка с ботом, светлая и тёмная темы (солнце и облака или луна и тучи)
- Общий мир: все пользователи одного сервера видят одни и те же машины

## Что понадобится

Только **Node.js версии 18 или новее** ([скачать](https://nodejs.org)). Внешних зависимостей нет, `npm install` не нужен.

Проверить, что Node установлен:

```bash
node --version
```

## Быстрый старт

```bash
git clone https://github.com/NickValen/taxiapp.git
cd taxiapp
npm start
```

Откройте в браузере: **http://localhost:3000**

В терминале появится строка `Жёлтый такси: http://localhost:3000`. Чтобы остановить сервер, нажмите `Ctrl+C`.

Если вы скачали ZIP вместо `git clone`, распакуйте архив, зайдите в папку проекта в терминале и выполните `npm start`.

## Как пользоваться

1. В меню выберите город.
2. Кликните на перекрёсток на карте (или на значок места): это точка «откуда». Второй клик, не ближе 4 кварталов от первого, задаёт «куда».
3. Выберите тариф и нажмите «Заказать».
4. Колесо мыши и перетаскивание двигают карту, кнопки «+», «−», «⌖» масштабируют её.
5. Вернуться к выбору города можно кнопкой с названием города вверху справа.

## Настройка

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `SIM_SPEED` | `1` | скорость симуляции (`2` — вдвое быстрее) |
| `DB_FILE` | `backend/data/db.json` | файл, где хранятся отзывы и история поездок |

Примеры запуска с настройками:

```bash
# macOS / Linux
PORT=8080 SIM_SPEED=2 npm start

# Windows PowerShell
$env:PORT=8080; $env:SIM_SPEED=2; npm start

# Windows cmd
set PORT=8080&& set SIM_SPEED=2&& npm start
```

Запускаются интеграционные тесты API: города, маршруты и цены, весь жизненный цикл заказа, отмена, валидация, отзывы, поддержка, поток событий.

## Запуск в Docker

```bash
docker build -t taxi .
docker run -p 3000:3000 taxi
```

Затем откройте http://localhost:3000. Чтобы сохранять отзывы и историю между перезапусками контейнера, подключите том:

```bash
docker run -p 3000:3000 -v taxi-data:/app/backend/data taxi
```

## Показать друзьям

Сервер должен быть запущен, а браузер друга должен до него достучаться. Варианты:

- в одной Wi-Fi сети откройте `http://<IP-вашего-компьютера>:3000`;
- через туннель, пока сервер работает: `npx cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`;
- задеплоить на любой хостинг с Node.js или Docker.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `node: command not found` | Установите Node.js и откройте новый терминал |
| `EADDRINUSE: address already in use` | Порт занят. Запустите на другом: `PORT=3001 npm start` |
| В браузере «Не удаётся связаться с сервером» | Сервер не запущен или страница открыта не по адресу `http://localhost:3000` |
| Страница пустая, если открыть `index.html` двойным кликом | Так нельзя: фронтенд работает только через сервер (`npm start`) |
| Первая загрузка идёт 1–3 секунды | Это нормально: загружается геометрия пяти городов |

## Как это устроено

- Сервер при старте строит города и ведёт симуляцию: 28 машин на город, боты-пассажиры, час пик. Тикают только города, на которые кто-то смотрит или где есть заказы.
- Маршруты считаются по графу дорог алгоритмом Дейкстры. Пробки замедляют машины и удорожают участок, перекрытые дороги объезжаются.
- Цена = тариф × расстояние × коэффициент спроса (доля занятых машин).
- Клиент один раз получает геометрию города, позиции машин приходят потоком SSE (около 10 раз в секунду, между кадрами движение экстраполируется), статус заказа запрашивается опросом.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/cities` | список городов |
| GET | `/api/cities/:id` | геометрия, граф дорог, объекты города |
| GET | `/api/cities/:id/stream` | SSE: машины, спрос, режим часа пик |
| GET | `/api/cities/:id/quote?from=&to=` | маршрут, этапы, цены по тарифам, время подачи |
| POST | `/api/cities/:id/rush` | `{on}`: включить или выключить час пик |
| POST | `/api/orders` | `{city, pick, drop, tariff}`: создать заказ |
| GET / DELETE | `/api/orders/:id` | статус заказа / отмена |
| GET | `/api/trips` | история поездок клиента (заголовок `X-Client-Id`) |
| POST | `/api/trips/:id/rating` | `{rating}`: оценить поездку |
| GET / POST | `/api/reviews` | отзывы |
| GET | `/api/faq` | частые вопросы |
| POST | `/api/support` | `{message}`: ответ бота поддержки |
| GET | `/api/health` | проверка работоспособности |

Идентификаторы городов: `paris`, `amsterdam`, `vienna`, `rome`, `london`.
